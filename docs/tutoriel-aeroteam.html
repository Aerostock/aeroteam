1. Introduction

AeroTeam est une application web de gestion de la charge de travail pour les équipes de maintenance aéronautique. Elle permet de :

  • Importer la charge de travail depuis un fichier issu de Victory Tracking ;
  • Visualiser les tâches regroupées par zone de travail et par bloc ;
  • Créer des équipes et pré-enregistrer les techniciens ;
  • Affecter les tâches (par bloc, par zone ou ligne par ligne) ;
  • Préparer la vacation suivante à partir de la charge restante ;
  • Exporter le planning et imprimer la charge d'une équipe ;
  • Retrouver ses données sur n'importe quel appareil.
Application web Aucune installation n'est nécessaire. L'application se lance dans un navigateur moderne (Chrome, Edge, Safari). Il vous suffit d'en connaître l'adresse.

2. Prérequis : accès à Victory Tracking

Pour alimenter l'application, vous devez disposer d'un accès à Victory Tracking, l'outil de suivi de maintenance du site. C'est de lui que proviennent les fichiers de charge de travail importés.

2.1 Ce dont vous avez besoin

  • Un identifiant et un mot de passe valides pour Victory Tracking (compte leader) ;
  • L'éditeur de rapports / exports accessible depuis votre session Victory Tracking ;
  • La possibilité de générer et télécharger un rapport au format CSV.

2.2 Le fichier CSV attendu

Le fichier à importer est un export CSV du Workpackage Report (rapport de charge de travail). Il doit contenir notamment les colonnes suivantes :

ColonneExempleUtilité dans AeroTeam
Task_NameRévision de la commande de volLibellé de la tâche (affiché partout)
Seq._Nr.25ANuméro de la ligne (N°)
Skill(s)CABB-MECHMétier / spécialité
MTX StatusACTV / PAUSEStatut (les lignes ACTV et PAUSE sont conservées)
Task_TypeJIC / CORR / MPCBloc de la tâche (couleurs, filtres, tuiles)
Work AreaFuselage avantZone de travail
Scheduled Hours8,0Heures planifiées
Aircraft RegistrationF-GKXTImmatriculation de l'appareil
Vérification du format Si la colonne Task_Name est introuvable dans le fichier, l'import refusera le fichier avec un message explicite. Contrôlez l'export dans Victory Tracking avant de l'emporter.
Bon à savoir A l'import, les lignes dont le champ Skill ne commence pas par CABB et celles dont le statut est différent de ACTV ou PAUSE sont automatiquement filtrées. Le nombre de lignes conservées / exclues est affiché après l'import.

2.3 Préparer la charge restante pour la vacation suivante

En fin de journée, le même principe s'applique : générez depuis Victory Tracking l'export de la charge restante et utilisez l'onglet « Préparation vac suivante » (voir chapitre 10).

3. Se connecter à son profil

Chaque leader utilise un code personnel qui lui sert de clé d'accès. Avec ce code, vous retrouvez votre profil et toutes vos données (équipes, tâches, affectations, notes) quel que soit l'appareil.

1
Ouvrez AeroTeam
Saisissez l'adresse de l'application dans le navigateur (ordinateur, tablette ou téléphone).
2
Saisissez votre code personnel
Le champ est masqué (affiché sous forme d'étoiles). Validez avec la touche Entrée ou le bouton « Se connecter ».
3
Vous êtes connecté
Le tableau de bord s'affiche avec le nom de votre profil en haut à droite.
Code inconnu ? Si le code saisi ne correspond à aucun profil, un message d'erreur s'affiche : « Aucun profil ne correspond à ce code ». Vérifiez l'orthographe (le code est sensible à la casse).

5. Import Victory — charger votre fichier de charge

Cet onglet permet d'importer le fichier CSV du Workpackage Report généré par Victory Tracking.

1
Cliquez ou glissez-déposez
Dans l'onglet Import Victory, cliquez sur la zone de dépôt ou glissez-déposez votre fichier (.csv, .xlsx, .xls).
2
Aperçu puis import
Un aperçu s'affiche avec les lignes conservées après filtres (Skills CABB*, statuts ACTV/PAUSE), ainsi que les statistiques (lignes totales, conservées, exclues). Cliquez sur « Importer les tâches » pour confirmer.
3
Vérifiez le résultat
Un message de confirmation indique le nombre de tâches importées. La liste des blocs importés (JIC, CORR, MPC…) et leurs quantités s'affichent en bas de page.
Les tâches ne sont pas doublées Si vous importez deux fois le même fichier, les lignes déjà présentes (mêmes numéros) sont automatiquement ignorées. Vous pouvez importer consécutivement plusieurs fichiers pour cumuler la charge.

6. Tableau de bord

Le tableau de bord est la vue d'ensemble de votre workpackage :

6.1 Indicateurs

  • Tâches totales, tâches assignées, non assignées et heures totales.

6.2 Répartition par bloc

Barres de répartition pour chaque bloc (JIC, CORR, MPC…) avec nombre et pourcentage.

6.3 À traiter (non assignées)

Les tâches non affectées, regroupées par bloc (repliées par défaut, dépliez avec un clic), puis par zone.

6.4 Récap détaillé de la charge par équipe

Pour chaque équipe : nombre de tâches, prénoms des membres, charge moyenne par membre, et le détail des blocs / zones affectés avec les numéros de lignes.

6.5 Charge d'une équipe en détail

Cliquez sur une ligne d'équipe pour ouvrir le pop-up détaillant ses tâches (TRFX, N°, Type, Bloc, Tâche, Appareil). Le bouton « Imprimer » permet d'imprimer la charge de l'équipe (voir chapitre 14).

7. Gestion des équipes

7.1 Pré-enregistrer les techniciens

  • Saisissez les noms dans le champ (séparés par virgules) puis « Ajouter » ;
  • ou cliquez sur « Charger un fichier » pour importer une liste (.txt / .csv, noms séparés par ligne, virgule, point-virgule ou tabulation) ;
  • Les noms apparaissent sous forme de pastilles. Un X permet de retirer un membre.
Convention de nommage Les techniciens sont enregistrés avec leur civilité et leur nom complet, par exemple « Mr Farid Ayad » ou « Mme Lea Damagnez ». Dans le tableau de bord, seuls les prénoms (Farid, Lea…) sont affichés sous le nom des équipes.

7.2 Créer une équipe

1
Cliquez sur « Nouvelle équipe »
Saisissez le nom de l'équipe (ex : « Équipe mécanique matin »).
2
Cochez les membres
Cochez les techniciens pré-enregistrés concernés, puis validez « Créer l'équipe ».
3
Gérez les équipes existantes
Chaque carte d'équipe permet d'ajouter des membres depuis les pré-enregistrés, d'en retirer (X), ou de supprimer l'équipe (corbeille). Le nombre de tâches assignées est affiché.

8. Tâches par zone

Cet onglet permet de consulter la charge importée, groupée par zone de travail.

  • Le champ recherche filtre instantanément par libellé, zone, skills ou appareil ;
  • Le menu statut filtre selon l'état (ACTV, PAUSE, …) ;
  • La barre « Filtrer par bloc » permet de masquer / afficher certains blocs en un clic (une corbeille à côté d'un bloc supprime toutes ses tâches après confirmation) ;
  • Les zones sont repliées par défaut : cliquez sur l'en-tête coloré d'une zone pour la déplier ;
  • Dans une zone, les blocs présents sont indiqués par des pastilles (ex : JIC · 12).

Chaque ligne de tâche affiche : N° , libellé, bloc, skills, TRFX, statut, appareil et l'équipe affectée (ou « Non assignée »).

9. Affectation des tâches

L'affectation se fait depuis l'onglet Affectation, selon trois méthodes.

9.1 Par bloc complet

Chaque bloc (replié par défaut) propose en son en-tête un menu « — Affecter tout le bloc — » : choisissez une équipe pour lui attribuer toutes les tâches non assignées du bloc.

9.2 Par zone

Dépliez un bloc, puis utilisez le menu « — Toute la zone — » d'une zone pour affecter à une équipe toutes les tâches non assignées de cette zone.

9.3 Ligne par ligne

Dépliez jusqu'à la liste des lignes et choisissez l'équipe dans le menu déroulant de la tâche concernée. Une tâche affectée affiche la pastille de l'équipe ; le bouton ↩ la retire. Les lignes non affectées sont glissables : glissez-les directement sur une équipe (panneau droit) pour les y affecter.

Suivi de la répartition Le panneau droit « Équipes » synthétise pour chaque équipe les blocs et zones affectés ainsi que les numéros de lignes, et le nombre total de tâches.

10. Préparation vac suivante

Le leader du matin prépare la charge de travail de l'équipe de l'après-midi. En fin de journée, il charge l'export de la charge restante dans cet onglet, trié comme pour les tâches, avec une vue compacte en tuiles par bloc.

1
Chargez la charge restante
Dans l'onglet « Préparation vac suivante », cliquez ou glissez-déposez le fichier CSV de la charge restante (même format que l'import Victory).
2
Aperçu puis « Ajouter à la préparation »
Contrôlez l'aperçu, puis ajoutez les lignes à la préparation.
3
Consultez les tuiles
Les blocs apparaissent en tuiles repliées : compteur de lignes, total d'heures et nombre de zones. Dépliez une tuile pour voir, zone par zone, les sous-tâches (N°, libellé, heures). Une corbeille supprime une ligne ou un bloc entier ; « Tout effacer » vide la préparation.
Indépendant des tâches La préparation vac suivante est stockée séparément des tâches : elle n'impacte ni le tableau de bord ni l'affectation. Les données sont sauvegardées dans le cloud avec votre profil.

11. Export & sauvegarde

11.1 Télécharger le planning

  • Exporter en Excel : génère un fichier .xlsx avec toutes les tâches et leurs affectations ;
  • Exporter en JSON : sauvegarde structurée par équipe avec les tâches associées.

11.2 Résumé du planning

Indicateurs : tâches, assignées, non assignées, équipes, membres.

11.3 Zone danger — réinitialisation

Action irréversible « Tout réinitialiser » efface les tâches, équipes, affectations et la préparation. La liste des membres est conservée, ainsi que les notes du bloc-notes. Cette action ne peut pas être annulée.

12. Bloc-notes

L'onglet Bloc-notes permet de garder des notes sous forme de tuiles (couleur jaune), utiles pour des consignes, rappels ou informations partagées avec votre équipe.

  • Nouvelle note : crée une tuile avec un titre et un contenu ;
  • Chaque tuile peut être modifiée (crayon) ou supprimée (corbeille) ;
  • Les notes sont sauvegardées dans le cloud avec votre profil : retrouvées sur tous vos appareils ;
  • Elles survivent à la réinitialisation.

13. Synchronisation multi-appareils & session

13.1 Vos données sont dans le cloud

Toutes vos données (équipes, membres, tâches, affectations, préparation, notes) sont enregistrées automatiquement avec votre profil. En vous connectant avec votre code personnel depuis n'importe quel appareil, vous retrouvez exactement le même état de travail.

13.2 Session à durée limitée

Sécurité La session est automatiquement fermée après 12 heures d'inactivité. Le code personnel est alors redemandé. Cela garantit qu'un appareil laissé ouvert ne reste pas accessible indéfiniment.

13.3 Changer de profil / supprimer son profil

  • Le bouton de déconnexion (en haut à droite) permet de quitter le profil sans supprimer les données ;
  • Le bouton corbeille (à côté) supprime définitivement le profil et toutes ses données (double confirmation). Cette action est irréversible.

14. Imprimer la charge d'une équipe

1
Ouvrez la charge d'une équipe
Dans le Tableau de bord, cliquez sur une équipe dans le récap de charge.
2
Cliquez sur « Imprimer »
Le pop-up de l'équipe propose un bouton « Imprimer ».
3
Validez la boîte d'impression du navigateur
Seule la charge de l'équipe sélectionnée (tableau des tâches) sera imprimée.
Récapitulatif des bonnes pratiques
  1. Connectez-vous avec votre code personnel sur tous vos appareils ;
  2. Générez l'export CSV de la charge depuis Victory Tracking ;
  3. Importez-le via Import Victory ;
  4. Pré-enregistrez vos techniciens et créez vos équipes ;
  5. Affectez les tâches par bloc, zone ou ligne ;
  6. Suivez la charge sur le tableau de bord et imprimez-la si besoin ;
  7. Préparez la vacation suivante via Préparation vac suivante ;
  8. Conservez vos consignes dans le Bloc-notes.
